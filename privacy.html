Privacy Policy

AuraLabs Uploader · Last updated: October 17, 2026

What this application is

AuraLabs Uploader is a private automation tool operated by Aura Labs. It uploads videos created by Aura Labs to Aura Labs' own YouTube channel through the YouTube Data API. It is not offered to the public, and the only person who authorizes it is the operator.

What access it requests

The application asks the operator, once, to authorize access to the operator's own Google account and YouTube channel with the YouTube scopes needed to upload videos and set their visibility. It uses this access to send video files, titles, descriptions and tags, and to change the visibility of videos that Aura Labs published.

What data is collected and stored

The application does not collect personal data from any other person. The only credentials it stores are the operator's own OAuth tokens, kept on a private server controlled by the operator and not exposed publicly.

Sharing

Aura Labs does not sell, rent, share or disclose any Google user data to third parties.

YouTube API Services

This application uses YouTube API Services. By using it, the operator is bound by the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
